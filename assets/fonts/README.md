# Inter font

`inter-latin-variable.woff2` is an unmodified Inter font downloaded from Google
Fonts on 2026-10-23 for local hosting. It preserves the site's existing Inter
typeface and avoids a visitor request to the Google Fonts service.

- Family: Inter, normal style; variable weight axis 100–900 (default 400)
- Internal version: `Version 4.001;git-66647c0bb`
- Subset: Latin, 230 mapped characters; no italic file is included
- Size: 48,256 bytes
- SHA-256: `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62`
- Authoritative CSS: https://fonts.googleapis.com/css2?family=Inter:wght@100..900&display=swap
- Original font URL: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Typeface source: https://github.com/rsms/inter

this Latin subset use the site's fallback font.
