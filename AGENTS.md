# RX Decision project instructions

## Required brand context

Before any work affecting branding, UI, imagery, typography, diagrams or presentation, read `BRAND.md` in full and inspect the relevant source images in `assets/brand/`.

The user-approved RX Decision Brand System v1 is binding. The default logo is the one-line green **RX** and near-black **Decision** wordmark. The stacked white RX / Decision mark on green is a separate app icon. Keep the exact five colors, Inter hierarchy, geometry and usage rules in `BRAND.md`.

Never use `assets/rx-decision-logo-original.jpg` as a reference or approved asset. It contains a rejected turquoise Rx monogram that was mistakenly selected on 23 October 2026. Its filename, Git history and use in an earlier page do not make it authoritative.

Preserve the original bytes of user-supplied source images. Do not redraw, retype, generate or replace the logo based on similarity. Do not infer exact brand colors from compressed JPEG pixels; use the printed hex values and the written standard.

## Website constraints

Keep the existing static HTML, CSS and JavaScript architecture unless the user requests a substantive change that needs something else. Do not introduce a framework, backend or unrelated integration for visual work.

Preserve the meaning of the existing privacy notice. Strategic Healthcare Pte. Ltd. is the LinkedIn Analytics integration operator, not the stated owner of the clinical product. Work on this website does not authorize changes to LinkedIn OAuth, Social Gateway or Content Studio.

Use clinically accurate public wording: development status and principles do not establish clinical validation or readiness for patient care. Clinical decisions remain with the physician.

For a requested implementation, verify the actual rendered page and relevant responsive behavior before reporting completion. A successful build alone is insufficient.

The user's current explicit instructions take precedence over these repository notes. This file records project constraints; it does not grant additional permissions.
